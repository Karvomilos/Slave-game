ЗАДАЧА: Создать Telegram Mini App на основе файла index.html.

ШАГ 1: РАЗБИВКА ФРОНТЕНДА
- Прочитай файл index.html.
- Раздели его на три файла: index.html, style.css, script.js. Стили вынеси в style.css, логику в script.js.
- Убедись, что все кнопки и анимации работают после разбивки.

ШАГ 2: БЭКЕНД (PYTHON)
- Создай файл main.py (или app.py) на FastAPI.
- Подключи базу данных SQLite (файл database.db).
- Создай таблицу players: id (Telegram ID), username, coins, crystals, slaves_killed, current_slave_stats (JSON), vip_status.
- Напиши эндпоинт /api/load_data, который принимает initData от Telegram, валидирует его (используя токен из token.txt) и возвращает данные игрока. Если игрока нет — создает нового.
- Напиши эндпоинт /api/save_data, который сохраняет прогресс игрока в базу.

ШАГ 3: ИНТЕГРАЦИЯ TELEGRAM
- Подключи библиотеку aiogram или python-telegram-bot.
- Бот должен принимать команду /start. Если в команде есть параметр "game", отправлять сообщение: "Я ваша подножная чернь. И покажу, где можно меня испытать." с кнопкой "Вернуться в игру" (WebApp кнопка).
- Бот должен читать токен из файла token.txt (не хардкодь его в код).

ШАГ 4: СВЯЗЬ ФРОНТЕНДА И БЭКЕНДА
- В script.js добавь код, который при загрузке игры вызывает /api/load_data и подгружает сохраненный прогресс.
- При каждом действии (покормить, ударить, купить) вызывай /api/save_data, чтобы прогресс сохранялся.

ШАГ 5: ТАБЛИЦЫ ЛИДЕРОВ (ДВЕ ШТУКИ)
- Создай эндпоинт /api/leaderboard, который возвращает два списка:
  1. "Зал позора" (топ по полю slaves_killed).
  2. "Комната власти" (топ по времени жизни самого старого раба). Для этого в таблице players нужно поле oldest_slave_age_days (целое число, сколько дней живет самый старый раб).
- В интерфейсе игры (в script.js и index.html) добавь две вкладки или два блока для отображения этих таблиц.

ШАГ 6: ТРЕЙДИНГ (ЗАГЛУШКА)
- Добавь в интерфейс кнопку "Аукцион" (пока просто заглушку, которая выводит "Скоро!").

ШАГ 7: ДЕПЛОЙ (ПОДГОТОВКА)
- Напиши файл requirements.txt со всеми зависимостями (fastapi, uvicorn, aiogram, sqlite3, telegram-init-data).
- Напиши файл README.md с пошаговой инструкцией: как запустить локально, как задеплоить бэкенд на Render и фронтенд на Vercel.
- В README обязательно укажи, что для валидации initData используется библиотека telegram-init-data.

ВАЖНО: Работай автономно. Не задавай вопросов. Если чего-то не хватает — создавай заглушки. В конце выведи отчет о том, что сделано.
